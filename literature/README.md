# Literature Workspace

This directory is the auditable research record behind the mind map.

- `protocol.yaml` defines the question, boundary, eligibility rules, and
  synthesis method before full screening.
- `search-log.md` records exact discovery and citation-chaining activity.
- `source-inventory.csv` distinguishes discovered, screened, examined,
  included, excluded, inaccessible, duplicate, corrected, and overlapping
  sources.
- `evidence-matrix.csv` extracts comparable findings, context, interpretation,
  limitations, and appraisal.
- `notes/` stores one structured full-text appraisal per included source.
- `papers/` may hold local full texts only when law, license, and repository
  policy permit; source records must state the actual access level.
