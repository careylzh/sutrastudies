# Sutra Source Copies

This directory preserves source documents requested for study. Each file must
have adjacent provenance and license metadata. A local copy is not automatically
approved as evidence for the mind map; appraisal and claim-level extraction
remain in `literature/`.

`manifest.csv` records the source identity, version, license, and checksum used
by `make checks` to detect accidental alteration.

## Included

- `karandavyuha-sutra-the-baskets-display.pdf` — an unchanged official 84000
  PDF of *The Noble Mahāyāna Sūtra “The Basket’s Display”* (Toh 116), accompanied
  by `karandavyuha-sutra-the-baskets-display.metadata.md`.

Do not alter the 84000 translation or reuse it commercially. The translation is
licensed CC BY-NC-ND 3.0; quotations and copies require full attribution.
